Pumpi — Alur Pembuatan Token & Fee

Dari klik "Launch Token" hingga token live di blockchain Solana

1
User isi data coin
Name, ticker symbol, deskripsi, dan upload gambar logo.
Gambar di-upload ke Object Storage (cloud) dan mendapat URL permanen.

✓ Gratis Belum ada tx Solana
2
Upload metadata ke pump.fun
Pumpi mengirim nama, simbol, deskripsi, dan URL gambar ke API pump.fun.
pump.fun menyimpan metadata dan mengembalikan URI (tautan ke JSON metadata on-chain).

✓ Gratis Belum ada tx Solana
3
Build transaksi via pumpportal
Pumpi memanggil pumpportal API untuk membuat transaksi Solana yang berisi: semua instruksi pembuatan token (mint account, bonding curve, metadata) + instruksi platform fee Pumpi. Transaksi dikembalikan sebagai raw bytes — belum ditandatangani.

✓ Gratis Belum dikirim ke Solana
4
Wallet popup — user approve
Transaksi ditampilkan di Phantom / Backpack / Solflare.
User melihat estimasi total cost dan memilih Approve atau Reject.

⚠ SOL akan dikurangi dari wallet
5
Transaksi ditandatangani & dikirim ke Solana
Wallet user menandatangani. Pumpi juga menandatangani dengan mint keypair baru (kunci unik untuk mint account).
Transaksi dikirim ke Solana RPC. Dicoba hingga 5x jika gagal (network congestion).
6
Token live — Pumpi register ke database
Setelah transaksi confirmed, Pumpi menyimpan data token ke database internal.
Token langsung muncul di halaman Explore dan chart mulai tracking trades.

✓ Token siap diperdagangkan

Kenapa pump.fun bilang "Create = 0 SOL"?
Mereka tidak memungut platform fee mereka sendiri saat create. Tapi Solana Account Rent (~0.007 SOL) tetap harus dibayar di pump.fun langsung juga — itu bukan fee pump.fun, itu persyaratan protokol Solana.
